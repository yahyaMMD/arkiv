Arkiv — Windows
===============

What to send the client
-----------------------
Send the file: Arkiv-Windows.zip

What the client does
--------------------
1. Unzip Arkiv-Windows.zip anywhere (Desktop is fine)
2. Open the Arkiv folder
3. Double-click Arkiv.exe
4. Open Settings and paste an OpenRouter API key
5. Click Choose a folder and select the library folder

Notes
-----
- Windows 10/11 64-bit
- Keep the whole folder together (do not move only Arkiv.exe)
- First launch may show a SmartScreen warning: More info → Run anyway
- Short excerpts of files are sent to OpenRouter for classification
