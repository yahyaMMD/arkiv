Opening the library…

One folder, kept in order

Give Arkiv a folder. It will file everything inside it.

Arkiv reads each file, chooses a category, and moves it into a folder inside that same library. Anything you add later is classified the same way.

  1. 01Choose the folder Arkiv is allowed to use.
  2. 02Every file is read and filed, one by one.
  3. 03New files in that folder are classified too.

Names and short excerpts are sent to OpenRouter so the model can read them. The files stay on this Mac.
